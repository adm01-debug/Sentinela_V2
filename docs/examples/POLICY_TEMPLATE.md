# Example: Policy Template
```markdown
# Acceptable Use Policy
## Purpose
This policy defines acceptable use of company computer resources.
## Scope
All employees using company-provided devices.
## Guidelines
1. Use resources for business purposes
2. Do not access inappropriate content
3. Report security incidents immediately
## Monitoring
Employee activity is monitored for security and compliance.
## Acknowledgment
I have read and agree to this policy.
Signature: _________________ Date: _________
```
