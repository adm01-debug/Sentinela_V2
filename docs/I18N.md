# Internationalization (i18n)

Sentinela supports multiple languages using i18next.

## Setup

The i18n configuration is in `src/lib/i18n.ts`.

## Supported Languages

- Portuguese (Brazil) - `pt-BR` (default)
- English (US) - `en-US`

## Usage

```tsx
import { useTranslation } from "react-i18next";

function MyComponent() {
  const { t } = useTranslation();
  return <h1>{t("common.save")}</h1>;
}
```

## Adding Translations

1. Add keys to `src/locales/pt-BR.json`
2. Add keys to `src/locales/en-US.json`

```json
{
  "myFeature": {
    "title": "My Feature",
    "description": "Feature description"
  }
}
```

## Switching Languages

```tsx
import { useTranslation } from "react-i18next";

function LanguageSwitcher() {
  const { i18n } = useTranslation();
  return <button onClick={() => i18n.changeLanguage("en-US")}>English</button>;
}
```

## Adding New Languages

1. Create `src/locales/{locale}.json`
2. Add to `src/lib/i18n.ts` resources
