# Monitoring Setup Guide

## Desktop Agent Installation

1. Download agent from Settings > Downloads
2. Install on employee workstation
3. Agent auto-connects using organization key

## Screenshot Configuration

- Interval: 5 minutes default
- Quality: 80% JPEG
- Blur sensitive: Enable in Rules

## Activity Tracking

Tracks: Apps, URLs, Idle time, Keystrokes (optional)

## Alerts Setup

Configure alerts in Settings > Alerts for:

- Idle time exceeded
- Blocked site visited
- Working outside hours
