# Compliance Guide

## Overview

Compliance requirements and certifications for Sentinela.

## Certifications

### SOC 2 Type II

- **Status**: Certified
- **Scope**: Security, Availability, Confidentiality
- **Renewal**: Annual

### GDPR

- **Status**: Compliant
- **Scope**: EU data processing
- **DPO**: dpo@sentinela.app

### HIPAA

- **Status**: Ready
- **Scope**: Healthcare customers
- **BAA**: Available upon request

## Compliance Controls

### Data Protection

- Encryption at rest (AES-256)
- Encryption in transit (TLS 1.3)
- Data retention policies
- Right to erasure support

### Access Control

- Role-based access (RBAC)
- Multi-factor authentication
- Session management
- Audit logging

### Security

- Vulnerability scanning
- Penetration testing
- Incident response plan
- Business continuity plan

## Compliance Reports

- SOC 2 Report (available under NDA)
- GDPR Data Processing Agreement
- Security Questionnaire (SIG Lite)
- Penetration Test Summary

## Audit Support

Contact compliance@sentinela.app for:

- Compliance documentation
- Security questionnaires
- Audit support
