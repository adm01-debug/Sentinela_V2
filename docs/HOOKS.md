# React Hooks Catalog

## Overview
Custom hooks used in Sentinela.

## Authentication
- `useAuth` - Authentication state
- `useAuthPage` - Auth page logic

## Data
- `useEmployees` - Employee data
- `useViolations` - Violation data

## UI
- `useTheme` - Theme management
- `useToast` - Toast notifications

See `src/hooks/` for implementations.
