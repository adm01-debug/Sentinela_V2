# Tutorial: Desktop Agent Installation

## Step 1: Download Agent

Settings > Downloads > Desktop Agent

- Windows: .exe installer
- macOS: .dmg installer
- Linux: .deb/.rpm package

## Step 2: Install

Run installer with admin privileges.

## Step 3: Configure

Enter organization key when prompted.

## Step 4: Verify

Agent icon appears in system tray. Status shows "Connected".

## Features

- Screenshot capture
- App/URL tracking
- Idle detection
- Keystroke analytics

## Silent Install (Enterprise)

```bash
sentinela-agent.exe /S /ORG_KEY=xxx
```
