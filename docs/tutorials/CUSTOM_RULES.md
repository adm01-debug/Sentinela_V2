# Tutorial: Creating Custom Rules

## Step 1: Navigate to Rules

Settings > Rules > Create Rule

## Step 2: Define Conditions

```
IF app_name CONTAINS "game"
AND time_spent > 30 minutes
THEN trigger_alert
```

## Step 3: Set Actions

- Block application
- Send alert
- Log violation
- Notify manager

## Step 4: Test Rule

Use **Test** button with sample data.

## Examples

- Block social media during work hours
- Alert if USB device connected
- Notify if large file downloaded
