# Tutorial: Mobile App Setup

## Step 1: Download App

- iOS: App Store > Sentinela
- Android: Play Store > Sentinela

## Step 2: Login

Use your web credentials or scan QR code from Settings > Mobile.

## Step 3: Enable Permissions

- Location (for geofencing)
- Notifications

## Step 4: Features

- View team activity
- Receive alerts
- Approve requests
- View reports

## Troubleshooting

- Check internet connection
- Ensure app is updated
- Re-login if token expired
