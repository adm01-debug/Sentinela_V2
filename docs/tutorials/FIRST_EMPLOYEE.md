# Tutorial: Adding Your First Employee
## Step 1: Navigate to Employees
Click **Employees** in the sidebar.
## Step 2: Click Add Employee
Click the **+ Add Employee** button.
## Step 3: Fill Details
- Name: John Doe
- Email: john@company.com
- Department: Engineering
- Role: Developer
## Step 4: Send Invitation
Click **Send Invite**. Employee receives email with setup instructions.
## Step 5: Install Agent
Employee installs desktop agent using the link in email.
## Verification
Check employee appears as "Online" in dashboard.
