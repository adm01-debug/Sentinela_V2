# Tutorial: Using Geofencing
## Step 1: Enable Geofencing
Settings > Features > Enable Geofencing
## Step 2: Create Geofence
Click **+ Add Geofence**
- Name: Office HQ
- Type: Circle or Polygon
- Draw on map or enter coordinates
- Radius: 100 meters
## Step 3: Set Rules
- Alert on entry
- Alert on exit
- Work hours only
## Step 4: Assign
Apply to specific teams or all employees.
## Use Cases
- Verify office attendance
- Field worker tracking
- Remote work compliance
