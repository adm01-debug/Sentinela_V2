# Tutorial: Exporting Data

## Step 1: Navigate to Export

Settings > Data > Export

## Step 2: Select Data Type

- Employee data
- Activity logs
- Screenshots
- Reports

## Step 3: Choose Format

- CSV
- JSON
- Excel
- PDF

## Step 4: Set Date Range

Select the period to export.

## Step 5: Download

Click **Export** and download when ready.

## GDPR Compliance

Use **Right to Access** export for employee data requests.
