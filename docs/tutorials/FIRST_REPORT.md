# Tutorial: Creating Your First Report
## Step 1: Navigate to Reports
Click **Reports** in sidebar.
## Step 2: Choose Report Type
- Productivity Report
- Activity Summary
- Time Tracking
- Violation Report
## Step 3: Set Parameters
- Date Range: Last 7 days
- Employees: All or specific
- Format: PDF or Excel
## Step 4: Generate
Click **Generate Report**. Download when ready.
## Scheduling Reports
Enable **Schedule** to receive reports automatically via email.
