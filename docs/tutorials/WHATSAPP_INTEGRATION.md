# Tutorial: WhatsApp Integration
## Step 1: Enable Integration
Settings > Integrations > WhatsApp > Enable
## Step 2: Connect Number
Scan QR code with WhatsApp Business app.
## Step 3: Configure Notifications
Choose which alerts send to WhatsApp:
- Violations
- Daily summaries
- Urgent alerts
## Step 4: Add Recipients
Enter phone numbers for notifications.
## Commands
- `!status` - Get current status
- `!report` - Quick report
- `!help` - List commands
## Limitations
- Max 1000 messages/day
- Text only (no images)
