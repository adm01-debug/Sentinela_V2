# User Guide

## Dashboard

The dashboard provides an overview of employee activity and productivity metrics.

### Key Metrics

- **Active Employees**: Currently online employees
- **Productivity Score**: Average productivity percentage
- **Alerts**: Unacknowledged security alerts
- **Total Hours**: Hours worked today

### Charts

- Activity timeline
- Productivity trends
- Application usage
- Department comparison

## Employees

Manage and monitor employee activity.

### Features

- View employee list
- Filter by department/status
- View individual profiles
- Activity history
- Screenshot gallery

## Reports

Generate and export reports.

### Report Types

- Daily activity
- Weekly productivity
- Application usage
- Attendance

### Export Formats

- PDF
- CSV
- Excel

## Alerts

Monitor and respond to security alerts.

### Severity Levels

- Critical: Immediate action required
- High: Review within 24 hours
- Medium: Review within 1 week
- Low: Informational

## Settings

Configure application settings.

### General

- Company name
- Timezone
- Date format

### Security

- Two-factor authentication
- Session timeout
- Password policy

### Notifications

- Email alerts
- Push notifications
- Slack integration
