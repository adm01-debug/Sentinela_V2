# Supabase Edge Functions

## Overview

Serverless functions for backend logic.

## Categories

- **Notifications**: send-email, send-sms, send-push
- **Reports**: generate-report, export-data
- **Analytics**: calculate-analytics, detect-anomaly
- **Security**: validate-token, enable-mfa

## Deployment

```bash
supabase functions deploy <function-name>
```
