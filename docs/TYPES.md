# TypeScript Types

## Overview

This document describes the TypeScript types used in Sentinela.

## Core Types

- `Employee` - Employee entity
- `Violation` - Violation entity
- `Report` - Report entity

## API Types

- `ApiResponse<T>` - Generic API response
- `PaginatedResponse<T>` - Paginated response

See `src/types/` for full type definitions.
