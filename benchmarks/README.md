# Benchmarks

Performance benchmarks for Sentinela modules.

## Running Benchmarks

```bash
npm run benchmark
```

## Available Benchmarks

- `circuit-breaker.bench.ts` - Circuit breaker performance
- `cache.bench.ts` - Cache operations
- `rate-limiter.bench.ts` - Rate limiting throughput
- `validation.bench.ts` - Validation performance

## Results

Results are saved to `benchmarks/results/`.
