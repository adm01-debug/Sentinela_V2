# Templates
Code templates for common patterns.
## Usage
Copy the template and modify as needed.
## Available Templates
- component/ - React component
- hook/ - Custom hook
- page/ - Page component
- service/ - API service
- store/ - Zustand store
- edge-function/ - Supabase edge function
- test/ - Vitest test
- story/ - Storybook story
- migration/ - SQL migration
