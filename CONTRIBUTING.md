# Contributing to Sentinela

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a feature branch

## Development Setup

```bash
npm install
npm run dev
```

## Code Style

- Use TypeScript
- Follow ESLint rules
- Use Prettier for formatting
- Write tests for new features

## Commit Messages

Follow Conventional Commits:

- `feat:` New feature
- `fix:` Bug fix
- `docs:` Documentation
- `style:` Formatting
- `refactor:` Code refactoring
- `test:` Adding tests
- `chore:` Maintenance

## Pull Requests

1. Update documentation
2. Add tests
3. Ensure CI passes
4. Request review

## Code Review

- Be respectful
- Focus on code, not person
- Explain your reasoning

## Questions?

Open an issue or reach out to maintainers.
