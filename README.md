# Sentinela

Employee Monitoring & Productivity Platform

## Features
- Real-time activity tracking
- Screenshot capture
- Productivity analytics
- Alert system
- Report generation
- Mobile app
- Desktop agent

## Quick Start
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Run tests
npm test

# Build for production
npm run build
```
